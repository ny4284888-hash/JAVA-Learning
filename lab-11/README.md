# Assignment 11: Bubble Sort and Selection Sort

## Aim
To sort arrays in increasing order using Bubble Sort and Selection Sort, and count swaps in Bubble Sort.

## 1. Bubble Sort
Bubble Sort is a sorting technique that compares two adjacent elements and swaps them if they are in the wrong order.

It repeats this process until the array is sorted.

**Example**
int[] arr = {5, 1, 4, 2, 8};


**Output:**

Sorted: [1, 2, 4, 5, 8]


## 2. Selection Sort
Selection Sort finds the smallest element from the unsorted part of the array and places it at the correct position.

It repeats this process until all elements are sorted.

**Example:**

int[] arr = {64, 25, 12, 22, 11};


**Output:**
![alt text](image.png)
Sorted: [11, 12, 22, 25, 64]


## 3. Swap Count in Bubble Sort
A swap means exchanging the positions of two elements.

In Bubble Sort, we increase the swap counter whenever two elements change their positions.

**Output:**

Swaps: 4


## 4. Important Concepts
 Array - Stores multiple values 
 Bubble Sort - Compares adjacent elements 
 Selection Sort - Selects the smallest element 
 Swap - Exchanges two values 
 `arr.length` - Gives the array size 
 `temp` - Temporarily stores a value

In this assignment, we learned how to sort arrays using Bubble Sort and Selection Sort. We also learned how to count swaps in Bubble Sort.
