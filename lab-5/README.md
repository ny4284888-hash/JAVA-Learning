# Assignment 5: Arrays – Traversal and Counting

## Aim
To create an array, access every element using a loop, and calculate the sum, largest value, and count of elements.

## 1. Array
An array is a collection of elements of the same data type stored in a single variable.

Example:
java
int arr[] = {3, 4, 5};


## 2. Array Index
Index is the position of an element in an array. Array indexing starts from 0.

Example:
- Index 0 = 3
- Index 1 = 4
- Index 2 = 5

## 3. Array Traversal
Array traversal means visiting each element of an array one by one using a loop.

**Example:**
```java
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

## 4. arr.length
The `length` property tells us the total number of elements in an array.

## 5. Sum of Array Elements
Sum means adding all the elements of an array.

**Example:**
```text
12 + 45 + 7 + 33 + 21 = 118
```

## 6. Largest Element
The largest element is the maximum value present in an array. We can find it by comparing each element using an if condition.

## 7. Counting Elements
Counting means finding how many elements satisfy a given condition.

**Example:** Count values greater than 10 in:
```text
5, 12, 2, 14, 7
```
The answer is 2 because 12 and 14 are greater than 10.

## 8. Important Operators
- `++` increases a variable by 1.
- `>` checks whether one value is greater than another.
- `+` adds two values.

## Conclusion
In this assignment, we learned how to create and traverse arrays using loops, access array elements through indexes, calculate the sum, find the largest element, and count values greater than 10.
