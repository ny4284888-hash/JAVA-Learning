# Assignment 14: Characters – Counting and Positions

## Aim
To use `charAt()` to count vowels, count letters and print character positions.

## 1. charAt()
`charAt()` is used to access a character at a specific position in a String.

## 2. Counting Vowels
Vowels are: a, e, i, o, u.

We use a loop and `charAt()` to count vowels.

**Output:**

Vowels: 3


## 3. Counting a Letter
We can count a particular letter using `charAt()` and an if condition.

**Output:**

Count of g: 2


## 4. Character Positions
We use a loop to print each character with its index. Index starts from 0.

**Output:**

0: h
1: e
2: l
3: l
4: o
