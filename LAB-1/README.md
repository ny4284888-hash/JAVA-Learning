Lab-1: Hello World, Variables and Arithmetic

Assignment 1

Aim
To print text, store values in variables and calculate using arithmetic operators.

Concepts and Theory

1. Java Basic Output
Java uses `System.out.println()` to display output on the screen. It prints the given text and moves to the next line.

2. Variables
A variable is a named memory location used to store data.

Example:
java
int roll = 101;


3. Data Types
Java provides different data types to store different kinds of values.

- `int` – Stores whole numbers.
- `double` – Stores decimal numbers.
- `char` – Stores a single character.
- `String` – Stores text.
4. Arithmetic Operators

 Operator --
 + :Addition 
 - :Subtraction 
 * : Multiplication 
 / : Division 
 % : Remainder 

5. Constants
The `final` keyword is used to declare a constant whose value cannot be changed after initialization.

Example:
java
final double PI = 3.14;

6. Circle Calculations

A circle has two important measurements:

- Area
- Perimeter (Circumference)
